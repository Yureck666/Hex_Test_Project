# Skills

Контекстные справочники для Claude. Используй `/luna`, `/performance` и т.д. чтобы подгрузить нужный скилл.

| Скилл | Описание |
|-------|----------|
| [`/luna`](luna/SKILL.md) | Luna SDK API, ограничения Bridge.NET/C# 7.3, запрещённый синтаксис и правила интеграции |
| [`/architecture`](architecture/SKILL.md) | Структура папок, соглашения об именовании, правила кода и стандарты проекта |
| [`/performance`](performance/SKILL.md) | Запрещённые паттерны в горячих путях (Update и др.): LINQ, GetComponent, аллокации |
| [`/serializable-curve`](serializable-curve/SKILL.md) | Замена `AnimationCurve` для Luna — паттерн `SerializableCurve` совместимый с Bridge.NET |
| [`/commit`](commit/SKILL.md) | Быстрый коммит всех изменений с автоматически сгенерированным сообщением |
